Grok Build unofficial

Design canvas

Visual only. grok.com chat surface: black field, pill composer, circular Send/Stop. Features stay. Start with Empty and Working. Resize the window like a VS Code split.

  1. Empty / first-run

    Quiet invitation, kbd hints, CLI-missing setup card, disabled composer.

  2. Working

    Task-type search icon in status, mixed SEARCH / READ / EDIT / RUN rows, Stop.

  3. Approval

    Write + command. Apply, Accept all, Run, Always allow, Reject, Never.

  4. Diff peek

    Path opens the editor. Inline peek in chat. diff button is VS Code side-by-side.

  5. Terminal

    RUN live output, collapsed git status, failed smoke — all in the chat row.

  6. Composer

    Attach, permission list, model, effort, Send, slash overlay, queue, overflow menu.

  7. History

    Left history drawer like grok.com. Search, rename, delete, rewind, worktree. Empty/Working show the collapsed rail.

  8. Question + plan

    Question card with Other… and Skip. Plan dock 3/7 above the composer.
