Grok Build unofficial · client walkthrough

Sidebar chat, grok.com feel

Unofficial VS Code client for Grok Build CLI. Features stay. Tools collapse. File names open the editor. Sun toggles light.

Presentation

    Setup card, composer disabled.

  2. Not signed in

    CLI on PATH. Sign-in card only.

  3. Start failed

    Process crash. Retry and View log.

  4. Starting

    Agent spawning. Composer disabled. Status starting…

    Empty field, Send live.

  4. Terminal

Composer

  1. Permission menu

    Ask / Accept / Plan / Bypass. Queue banner. Overflow.

  2. Effort menu

    Fast open. Auto through Heavy. ACP modeId.

  3. Model menu

    Grok 4.6 open. Other ids closed chips stay shut.

  4. Slash autocomplete

    /con. Menu above composer, not on Ask.

  5. Slash result

    /context modal. Used, prompt, reply, cached.

  6. Slash error

    /compact failed. Named, not a toast.

  7. Attachments

    Two thumbs, remove, +1 overflow.

  8. Agent stopped

    Restart pill on the right. No Send.
