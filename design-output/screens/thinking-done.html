Why does Always-allow forget newlines?

Always-allow keys the learned prefix to the full command line. commandPrefixes splits a command on &&, but never on \n, so a two-line paste stores one prefix with the newline baked in. The next single-line npm test misses the learned key, and the gate asks again.

Trim the trailing \n before learning, and split stored entries on newlines as well as &&. With that, a multi-line approval matches every line, and the gate stops re-asking inside the same session. I can patch permissions.ts if you want it.
