This is a solid unofficial VS Code ACP client: typed host/webview split, a real permission gate at the fs/terminal boundary, and a lot of production-minded UI work. The main gaps are no workspace sandbox, almost no unit tests, and a few concrete host bugs.

What it is

Grok Build (unofficial) 0.2.2 wraps grok agent stdio over JSON-RPC and renders a sidebar chat (Svelte 5). The host owns transcript, approvals, sessions, rewind, and worktrees; the webview is a renderer plus composer.

The split is the right one. Protocol quirks stay in GrokSession / AcpClient. The UI can change without touching the wire.

What is done well

  • Permission gate is real. Grok is spawned with bypassPermissions; this extension is the only ask/deny layer on fs/write_text_file and terminal/create.
  • Approvals still accept arbitrary cwd and env.
